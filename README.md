A one-page newspaper front page that sums up Thursday 19 November 2026: a masthead carrying the date, a world map dotted by the places the stories happened, and 35 short, verified stories arranged as headlines with a one-line summary each — five of the biggest given a larger "big stories" column. Every item is an event that happened or was first reported on 19 November 2026, chosen for breadth across politics, conflict, justice, markets, tech, science, climate, sport and culture and across six continents. The renderer (`render.py`, Python + Pillow) draws the whole page offline and deterministically from embedded data, including a simplified public-domain world map; the graded entrypoint (`main.ts`) copies the rendered `entry.png` to the output directory.

## Run it

```sh
node main.ts
```
